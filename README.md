# Pediculus
#### What is the effect of Dataset Size on the Classification Accuracy and False Positive Rate of a convolutional neural network trained to identify stock trends? 

## Overview

This project is dedicated to finding the effect of an Convolutional Neural Networks Classification accuracy when compared against dataset size.

This project was made for my 10th grade science project so it will follow the standard formula. Results will be published on my website, as well as in this repository at the bottom of this file.

## Setup

Make sure python 3.14 is installed, and then run this command:

<code>pip install -r requirements.txt</code>
